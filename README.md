# AI Business Sites

이 저장소에는 5개의 정적 웹 도구 사이트가 들어 있습니다.

- `01-seller-toolbox`: 이미지 리사이즈 도구
- `02-owner-calculator`: 자영업자 원가·마진 계산기
- `03-quote-maker`: 견적서 계산기
- `04-creator-toolkit`: 크리에이터 이미지 규격 변환기
- `05-parcel-calculator`: 택배 부피무게 계산기
